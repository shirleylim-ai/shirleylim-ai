## Featured work

### [Expenses Tracker AI](https://github.com/shirleylim-ai/Expenses-Tracker-AI) · [live demo](https://shirleylim-ai.github.io/Expenses-Tracker-AI/)

A private expense tracker: snap a receipt and the form fills itself in, then get a month-end forecast and spot unusual charges. It works with **no sign-up and no cloud AI**: everything runs in your browser.

- **Receipt scanning, auto-categorising and insights** that run on your own device
- **Export** to CSV, JSON or PDF, plus read-only share links with QR codes
- **Quality you can check:** strict TypeScript, 91 automated tests, CI on every change, and an honest list of limits in the README
